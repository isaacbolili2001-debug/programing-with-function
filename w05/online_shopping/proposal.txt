1. What is the title of your program?
ONLINE SHOPPING CART SYSTEM
A comprehensive Python application that simulates an online grocery shopping experience
where customers can browse products, add/remove items from their cart, calculate totals with
taxes, and generate purchase receipts.


2. What real-world problem will your program address or help to solve?
Problem Statement: Modern grocery stores need efficient online ordering systems to:
Allow customers to shop conveniently from home
Process orders quickly and accurately
Calculate prices, taxes, and totals without errors
Generate professional receipts for customers
Track inventory and customer purchases
Provide order history and statistics
Solution: This Online Shopping Cart System will:
✅ Enable customers to browse a product catalog (CSV file)
✅ Allow adding/removing items to/from shopping cart
✅ Calculate subtotals, apply sales tax (6%), and compute final totals
✅ Save orders to a CSV file for record-keeping
✅ Generate formatted receipts with date/time stamps
✅ Provide order history and basic statistics
✅ Handle errors gracefully (missing files, invalid products, permission issues)

3. What will you learn from developing this program?
1. File I/O & CSV Processing
Reading and writing CSV files
Parsing structured data
Handling file operations safely
2. Data Structures & Algorithms
Using dictionaries to store product catalogs
Using lists to manage shopping carts
Searching and filtering data efficiently
. Exception Handling
Catching FileNotFoundError (missing files)
Catching PermissionError (file access issues)
Catching KeyError (invalid product IDs)
Catching ValueError (invalid input)
Creating meaningful error messages
4. Mathematical Calculations
Calculating subtotals from quantities and prices
Applying percentage-based taxes
Rounding currency values correctly
Handling floating-point precision
Date/Time Operations
Getting current date and time
Formatting dates for display
Calculating future dates (delivery dates, return dates)
6. Function Design & Reusability
Writing pure functions (parameters + return values)
Separating concerns (UI vs. logic)
Creating testable, reusable components
Avoiding side effects in functions
Unit Testing with pytest
Writing test functions
Using assertions to verify behavior
Testing edge cases and error conditions
Using pytest.approx() for floating-point comparisons
8. Real-World Problem Solving
Breaking complex problems into smaller functions
Designing data structures for real applications
Implementing features based on requirements
Debugging and improving code iteratively

    (Remember also that it's hard to test functions that get user input
